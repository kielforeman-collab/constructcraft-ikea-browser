Built for Architectural Workflows

Fast local search, clean geometry, zero bloat

Engineered cleanly around ConstructCraft’s Plugin API 3—keeping IKEA endpoints entirely in the Lua plugin while giving core ConstructCraft reusable Draco decoding and catalog tooling.

01 / PERFORMANCE

Instant Search & Smooth 60 FPS UI

Built for 36,447 models without sluggishness: flat Structure-of-Arrays storage, an inverted word index, pooled TLS connections, and off-thread JPEG decoding keep the UI completely unblocked.

  • O(1) article lookup & 15× faster word search
  • Off-thread JPEG decode + bounded 192-texture LRU
  • Zero per-frame UI clones & full 36k sparse virtualization
02 / GEOMETRY & BIM

Pure-Rust Draco & IFC Ready

Every KHR_draco_mesh_compression GLB decodes natively in pure Rust with no C++ binaries, mapping automatically to ConstructCraft component kinds and IFC property sets.

  • Furniture, Casework, Lighting, Plumbing + IFC classes
  • Pset_IkeaProduct + clickable ikea.com ProductUrl
  • Automatic type reuse across repeated MCP placements
03 / SECURITY

Hardened, Host-Pinned & Opt-In

Network access is disabled until explicitly granted in Manage → Plugins. Every URL, redirect, cache path, and SHA-256 hash is validated—with zero broad filesystem access required.

  • HTTPS-only with redirect allowlist & // rejection
  • SHA-256 GLB verification & symlink-safe cache writes
  • Strict ikea.com / ikea.cn URL & JSON field validation

Model Context Protocol · v0.2.0+

Furnish BIM projects by prompt over MCP

Load IKEA Browser with ConstructCraft’s built-in ccad mcp server and any MCP-compatible AI client (Muse, Claude Desktop, Claude Code, Cursor) can search all 36,447 models and place real-scale furniture directly into your .ccad project.

ikea_browser__categories query

Returns top-level IKEA catalog category codes and item counts for structured discovery.

ikea_browser__search query

Filters 36,447 models by name, article number, category, color, or maximum W × D × H in meters.

ikea_browser__place edit

Downloads & SHA-256-verifies the Draco GLB, loads it with Pset_IkeaProduct IFC metadata, and places it at [x, y] with rotation and level in one undo step.

MCP Client Config (ccad mcp) 
{
  "mcpServers": {
    "constructcraft": {
      "command": "C:\\Program Files\\ConstructCraft\\ccad.exe",
      "args": [
        "--plugins",
        "%APPDATA%\\ConstructCAD\\data\\plugins",
        "mcp",
        "--lang",
        "en"
      ]
    }
  }
}

Works over stdio with isolated per-plugin cache read grants—no broad filesystem permission required.

Getting Started

Up and running in two minutes

Because IKEA Browser uses Plugin API 3 and native Draco decoding, download both the latest plugin archive and the matching ConstructCraft release build.

1. ConstructCraft (Plugin API 3)

v0.14.1-ikea.4

Pre-built installers for Windows (.msi), macOS Apple Silicon & Intel (.dmg), and Linux (.AppImage / .deb).

Download ConstructCraft Build ↗

2. IKEA Browser Plugin

v0.2.2

Lightweight Lua plugin package (ikea_browser-v0.2.2.zip, ~5 KB) with English & Portuguese translations and SHA-256 verification.

Download ikea_browser-v0.2.2.zip ↗
  1. Install ConstructCraft using constructcraft-v0.14.1-ikea.4-x86_64.msi from the release page.
  2. Unzip the plugin into your ConstructCraft plugins folder (shown in Preferences → File Locations):
    %APPDATA%\ConstructCAD\data\plugins\ikea_browser\
  3. Enable network access inside ConstructCraft via Manage → Plugins → IKEA Browser → Allow it to access the network, then click Reload.
  4. Browse & place: open Insert → Component Library, pick the IKEA tab, select any product, and click Load into Project.
