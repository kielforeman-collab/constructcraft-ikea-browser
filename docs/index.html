Built for Architectural Workflows

Fast local search, clean geometry, zero bloat

Engineered cleanly around ConstructCraft’s Plugin API 3—keeping IKEA endpoints entirely in the Lua plugin while giving core ConstructCraft reusable Draco decoding and catalog tooling.

01 / GEOMETRY

Native Pure-Rust Draco

Every GLB in the catalog uses KHR_draco_mesh_compression. ConstructCraft decodes compressed meshes natively in pure Rust with no C++ binaries or external CLI tools required.

  • Content-addressed SHA-256 disk cache
  • Verified against dataset hashes before load
  • Reusable component types per project
02 / BIM & IFC

Structured BIM Metadata

Imported models automatically map to ConstructCraft component kinds and export cleanly to IFC with article numbers, dimensions, and clickable product links.

  • Furniture, Casework, Lighting, Plumbing
  • IFCFURNITURE / IFCLIGHTFIXTURE / IFCSANITARYTERMINAL
  • Clickable ProductUrl in Properties panel
03 / SECURITY

Host-Pinned & Opt-In

Network access is disabled by default until you allow it in Manage → Plugins. Requests are strictly confined to Hugging Face hosts—no live price scraping or tracking.

  • HTTPS-only with redirect allowlist checks
  • Explicit opt-in per plugin in preferences
  • Direct ikea.com link for live pricing

Getting Started

Up and running in two minutes

Because IKEA Browser uses Plugin API 3 and native Draco decoding, download both the latest plugin archive and the matching ConstructCraft release build.

1. ConstructCraft (Plugin API 3)

v0.14.0-ikea.4

Pre-built installers for Windows (.msi), macOS Apple Silicon & Intel (.dmg), and Linux (.AppImage / .deb).

Download ConstructCraft Build ↗

2. IKEA Browser Plugin

v0.2.0

Lightweight Lua plugin package (ikea_browser-v0.2.0.zip, ~5 KB) with English & Portuguese translations and SHA-256 verification.

Download ikea_browser-v0.2.0.zip ↗
  1. Install ConstructCraft using constructcraft-v0.14.0-ikea.4-x86_64.msi from the release page.
  2. Unzip the plugin into your ConstructCraft plugins folder (shown in Preferences → File Locations):
    %APPDATA%\ConstructCAD\data\plugins\ikea_browser\
  3. Enable network access inside ConstructCraft via Manage → Plugins → IKEA Browser → Allow it to access the network, then click Reload.
  4. Browse & place: open Insert → Component Library, pick the IKEA tab, select any product, and click Load into Project.
